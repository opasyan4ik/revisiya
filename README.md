# Ревизия и приемка

Небольшое статическое PWA-приложение для приемки и ревизии товаров.

## Структура

- `index.html` — разметка страницы.
- `src/styles.css` — собственные стили и адаптивная верстка.
- `src/app.js` — импорт Excel, сканирование, фильтры, сохранение и экспорт.
- `manifest.webmanifest` — настройки PWA.

## Возможности

- загрузка ведомости из `.xlsx` и `.xls`;
- поиск по наименованию, артикулу и штрихкоду;
- ручной ввод и сканирование камерой;
- вкладки «Все», «Посчитано», «Не посчитано», «В процессе» и «Излишки»;
- автосохранение прогресса в `localStorage`;
- экспорт результата ревизии в Excel.

## Запуск

Откройте `index.html` через локальный статический сервер или разместите проект на GitHub Pages. Для камеры нужен HTTPS, поэтому обычное открытие файла через `file://` может не подойти.

Пример запуска через Python:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.
